# Interview drill sets

Ye **question-only drill sheets** hain — mock-interview ke liye. Study notes (concept + answers) `../` (parent folder) mein hain; ye wo sets hain jinhe **ek-ek karke bol ke** practise karna hai.

**Kaise use karein:**
1. Ek question padho → answer **bolo** (likho nahi) 2–4 sentence mein.
2. Har answer ke end mein *"in my project, …"* ShopFlow se jodo.
3. Atka? Wahi topic ki study note (`../NN-*.md`) mein wapas padho, drill-log table mein tick karo.
4. `[P]` (prod/failure) wale sabse zyada matter karte senior rounds mein.
